Files:
- index.html: semantic website content and sections
- styles.css: responsive design, typography, visuals and reduced-motion styles
- script.js: category filtering, expandable risk details, timeline slider, and a water-footprint infographic

How to preview:
Open index.html in a modern browser. Google Fonts require an internet connection; fallback fonts are included.

How to publish on GitHub Pages:
Upload index.html, styles.css, script.js, and this README to the repository root. The water-footprint section includes source-derived figures and links to EESI. In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.

Accessibility choices:
Semantic headings and sections, labeled slider, keyboard-operable buttons, aria-expanded states, external links with rel=noopener, and a reduced-motion preference.
